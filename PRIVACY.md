# Ebb Privacy Policy

Date: August 2, 2026

Ebb is a browser extension that limits how many supported social-media contexts and tabs are open at the same time.

## Information Ebb processes

Ebb checks the URLs and titles of currently open browser tabs to identify supported social-media platforms and apply the limits selected by the user.

This information is processed locally in the browser. Ebb does not collect, transmit, sell, share, or use browsing information for advertising or analytics.

## Information stored locally

Ebb stores the following settings in Chrome's local extension storage:

- Maximum active social-media platforms.
- Maximum tabs allowed per supported platform.
- Which supported sites are included in Ebb.

These settings remain on the user's device until they are changed, cleared or the extension is removed.

Ebb does not persist a browsing history or retain the URLs and titles of open tabs after they are no longer needed for the current limit check.

## Chrome permissions

Ebb uses the following permissions:

- `tabs`: to identify currently open supported social-media tabs, display them when a context limit is reached, and close a tab only after the user selects a close action.
- `storage`: to save the user's platform and tab limits locally in the browser.

## Data sharing and external services

Ebb does not send user data to the developer or any third party. It does not use remote analytics, advertising services, tracking services or external data-processing servers.

## Changes to this policy

If Ebb's data practices change, this policy will be updated before those changes are released. Any new collection or transmission of user data will be disclosed clearly.
